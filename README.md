# Karamaniya

**Karamaniya** is a persistent multi-agent AI evaluation environment designed to study **long-horizon behavior** under institutional constraints.

In Karamaniya, five language-model agents govern the same fictional country while occupying different offices, receiving asymmetric information, communicating privately, bargaining, voting on policy, issuing structured actions, and then facing consequences generated by a separate causal world engine.

The project is intended as **measurement science for persistent multi-agent AI systems**, not as a predictor of real-world politics.

## Why this project exists

Most LLM evaluations focus on short tasks, benchmarks, or isolated interactions.  
Karamaniya instead studies what happens when models must operate:

- over many sequential months,
- under role constraints,
- with partial and asymmetric information,
- with memory of prior decisions,
- with public and private communication,
- and with persistent consequences from earlier actions.

The core motivation is simple:

> **How much real disagreement, coordination, strategic adaptation, and behavioral variation gets hidden by final outcomes such as a unanimous vote or a stable-looking government?**

## Research focus

This project currently focuses on five main questions:

1. **Persistence:**  
   Do behavioral differences between models persist over long trajectories?

2. **Role effects:**  
   How much of observed behavior is driven by the model itself versus the office it occupies?

3. **Consensus versus trajectory:**  
   Can final agreement hide substantial disagreement earlier in the decision process?

4. **Measurement reliability:**  
   Which observed effects reflect genuine model behavior, and which are artifacts of the evaluation harness?

5. **Instrument design:**  
   How should a persistent multi-agent evaluation environment be validated before larger frontier-model studies?

## System overview

Karamaniya has two main layers:

### 1. Agent layer
Five LLM agents act as government delegates with different offices and responsibilities.  
They can:

- make public statements,
- exchange private messages,
- negotiate and bargain,
- table motions,
- vote,
- issue office-specific directives,
- record future-facing notes.

### 2. World engine
A separate deterministic simulation engine updates the state of the country month by month.  
It tracks outcomes such as:

- approval,
- inflation,
- food supply,
- military readiness,
- unrest,
- diplomacy,
- political stability,
- and institutional outcomes.

This separation is important: the **models choose actions**, but the **world consequences are computed by the engine**, not improvised by the models themselves.

## Pilot status

This repository contains materials from an initial **pilot / instrument-validation stage**.

The pilot was designed primarily to:

- test whether the harness can discriminate between model behaviors,
- surface confounds,
- identify protocol failures,
- inspect resignation/removal mechanics,
- and refine the design of a later frontier-model study.

### Current pilot snapshot
- **85 completed trajectories** included in the cleaned pilot analysis
- multiple framing conditions
- multiple seeds
- seat rotation across roles
- local small-model runs used to validate the measurement pipeline before larger compute requests

## Important caution

The pilot surfaced important confounds, including:

- vacancy persistence effects,
- removal/resignation artifacts,
- protocol-validity differences across models,
- and cases where outcome summaries could overstate substantive consensus.

Because of this, the pilot should be read primarily as **instrument validation**, not as a final scientific claim about model families.
