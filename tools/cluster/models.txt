# Eight fields, separated by spaces:
#   name       the served model name; a seat's model = this name, and its base_url uses this row's port
#   repo       the Hugging Face repository: open weights, not gated (a token would be a key on the box)
#   revision   a full 40-character commit hash of that repository, pinned; never a branch such as main
#   gpus       GPU indexes on the box, comma-separated; more than one means tensor parallelism

#   max_len    vLLM --max-model-len: the longest prompt plus the seat's max_tokens_cap must fit in it
